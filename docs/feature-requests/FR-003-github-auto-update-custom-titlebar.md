# FR-003 / Change Request 003

## Title
GitHub distribution, automatic update before start, custom title bar, and button-style cleanup.

## Requested behavior

- GitHub becomes the primary location for program source and versions.
- The user starts the app through one BAT file.
- Before the app opens, the BAT checks GitHub for a newer version.
- A newer version is installed automatically, then the app starts.
- Local API key and user settings must not be overwritten.
- The assistant should inspect repository commits and avoid duplicating completed work.
- The upper glossy shade on circular keys must be removed.
- The technical operating-system title frame must be removed.
- A custom title bar must provide minimize, maximize/restore, and close controls.
- Program downloads do not need to be attached in chat; GitHub is the distribution source.

## Implementation status

Implemented in version 4.3.0.
