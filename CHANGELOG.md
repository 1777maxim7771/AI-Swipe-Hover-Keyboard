# Changelog

## 4.3.0 — 2026-07-29

- Added `UPDATE_AND_START.bat`.
- Added GitHub version check through `latest.json` and self-update from the published multipart version package.
- Local API key, settings, position, learning data, language usage, and logs are preserved during update.
- Added custom title bar and custom minimize/maximize/close controls.
- Removed the upper glossy shade from ring buttons.
- Kept fixed ring coordinates and slot-for-slot ring content swapping.
- Added repository documentation for commit tracking and update workflow.

## 4.2.0

- Added two fixed concentric rings.
- Mouse wheel swaps only ring contents.
- Added dynamic button feedback, local T9 highlighting, and full-height word suggestions.
